# chart-render-engine-go

把**声明式图表描述**渲染成**可缩放矢量图（SVG）**的服务端引擎。
同一份输入在任何一次运行、任何一个并发任务中都产出**逐字节一致**的 SVG，
可直接用于快照比对与回归排查。

```go
spec, err := chart.ParseSpec(jsonBytes)        // 解析并校验
res, err := chart.NewEngine().Render(ctx, spec) // 渲染；可取消
// res.SVG          —— 完整 SVG 文本，可直接嵌入页面
// res.Diagnostics  —— 非致命问题列表（缺失值、降采样等）
```

命令行用法：

```sh
go run ./cmd/chart-render -in spec.json -diag > chart.svg
```

## 图表描述格式（JSON）

```jsonc
{
  "width": 640,              // 画布宽（px，必填，>0，<=32768）
  "height": 400,             // 画布高（px，必填）
  "title": "标题",            // 可选
  "legend": {                // 可选
    "visible": true,
    "position": "right"      // "right"（默认）或 "bottom"
  },
  "xAxis": {                 // 共享 x 轴（必填，可为 {}）
    "type": "linear",        // "linear"（默认）| "log" | "time"
    "label": "时间",
    "min": 0, "max": 100,    // 可选；缺省自动推导
    "ticks": 6               // 期望刻度数量（近似，默认 6，上限 20）
  },
  "yAxes": [                 // 可选；缺省自动生成一条线性轴
    {"id": "left",  "type": "linear", "label": "销量"},
    {"id": "right", "type": "log",    "label": "价格"}
  ],
  "palette": ["#3366cc", "..."],  // 可选，覆盖默认配色循环
  "maxPoints": 1000,              // 可选，单系列降采样后的点数上限（默认 1000）
  "series": [ ... ]               // 图元列表，按声明顺序叠加绘制
}
```

### 系列（series）

```jsonc
{
  "id": "s1",              // 可选，缺省为 "series-<序号>"
  "name": "华北",           // 图例显示名
  "type": "line",          // line | area | bar | stacked-bar | scatter
  "x": [1, 2, 3],          // 可选；缺省使用点下标 0..n-1
  "y": [10, null, 30],     // null 表示缺失值
  "yAxisId": "right",      // 可选；缺省绑定第一条 y 轴
  "color": "#ff0000",      // 可选；缺省按调色板循环
  "opacity": 0.8           // 可选，0..1，默认 1
}
```

- 多个图元在同一坐标系内**按声明顺序叠加**，先声明的先绘制。
- `bar` 为分组柱状（同 x 的多个 bar 系列并排）；`stacked-bar` 按声明顺序堆叠，
  堆叠范围按每个 x 的累计和推导，且始终包含零基线。
- 未知字段会被拒绝（`DisallowUnknownFields`），便于及早发现拼写错误。

## 坐标语义

- **linear**：线性映射；自动范围在数据范围外扩 5%，刻度落在 1/2/5 系列的"友好"位置。
- **log**：以 10 为底；刻度取 10 的幂（不足一个数量级时补 2/5 等中间刻度）。
  非正数值不参与渲染与统计，并产生 `log-non-positive` 诊断。
- **time**：x 值为 **Unix 秒**，刻度对齐 **UTC** 边界（与运行环境时区无关），
  阶梯为 1s/5s/…/1d/7d/30d/…，标签随步长在 `15:04:05` / `15:04` / `01-02` / `2006-01` 间切换。

### 共享轴与独立轴

- 所有系列共享同一条 x 轴，刻度统一。
- y 轴通过 `yAxisId` 组织：同一 id 的系列共享轴（范围为并集）；不同 id 各自独立。
  独立轴的摆放规则确定可复现：**第 0、2、4… 条轴在左侧，第 1、3、5… 条在右侧，
  同侧多轴按序号由内向外排列**，布局为每条轴预留与其刻度标签等宽的空间。

### 轴范围推导

`min`/`max` 缺省时自动推导；可只指定一端。退化输入有确定性的兜底：

| 输入                     | 结果                          |
|--------------------------|-------------------------------|
| 数据为空 / 全部缺失      | `[0, 1]` + `axis-fallback` 诊断 |
| 数据全部相同（v）        | `[v-|v|/2, v+|v|/2]`（v=0 时 `[0,1]`）|
| log 轴范围含非正值       | 钳到 `10^(floor(log10 hi)-1)` + 诊断 |

## 缺失与非法数据

- `null` → `missing-value`；`NaN`/`Inf` → `invalid-value`；两者都**不会当作 0**
  参与范围或统计，折线/面积在该处断线。
- 空系列（无可用点）→ `empty-series` 诊断，渲染继续。
- `x` 与 `y` 长度不一致 → `Validate` 直接报错（属于输入错误，非诊断）。
- 诊断按（系列， 原因）聚合计数，输出体积不受病态输入影响。

## 降采样

单系列点数超过 `maxPoints`（默认 1000）时启用 min-max 分桶降采样：
每个桶保留**首点、尾点、最小值、最大值**（按下标顺序去重），
因此每段极值与首尾点必然保留；全缺失的桶转化为断线标记。
算法是输入的纯函数，结果确定；输出点数 ≤ `maxPoints`，
渲染耗时与 SVG 体积随输入规模保持有界。

## 布局

标题、图例、轴标签、刻度标签先各自占位，绘图区取剩余空间，**互不重叠**；
画布变小时绘图区自适应收缩（下限 20px）。标签过密时按确定规则抽稀：
保留第 0、k、2k… 个，k 为使标签放得下（按 `字符数 × 7px` 估算）的最小整数。

## 确定性与并发

- 输出中所有坐标经统一的定点格式化（最多 2 位小数、去尾零、`-0` 归一）。
- 所有 map 遍历前按键排序；颜色按调色板确定循环；无随机数、无时区依赖。
- `Engine` 无状态，可并发使用；同一 spec 并发渲染结果逐字节一致。
- `Render` 在各阶段检查 `ctx`：取消返回 `ErrCanceled`，
  不产出半成品 SVG，也不遗留资源（全部内存在调用返回前释放）。
